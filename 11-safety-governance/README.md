# 11 安全与治理

> 目标：建立"Agent 会犯错、会被滥用、会产生真实影响"的责任意识。这是成为专家与成为"会调库的人"的分水岭。

> 视觉：本章共 8 页，各页在"概念真正需要图示"处嵌入了 1 张内容驱动的矢量图（最小权限链、纵深防御、注入链路、工具护栏、隐私流向、红队回归环、取证-归因链、门禁环），并配有解释段落。无"为图而图"的凑数。

## 为什么最后且持续

Agent 拥有读写文件、执行命令、访问网络的能力——也就是"你的权限"。能力越大，出事的代价越大。这一章不是可选附加，而是交付任何真实系统的必经环节。
