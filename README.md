# Agent 知识图谱

> 从大学基础出发，系统学习自然语言处理、大语言模型与 Agent 工程，最终能读懂并在真实系统（本仓库 `deepseek-harness`）上动手。每一页都可独立阅读，也支持跨页跳转与全文搜索。

## 这是一套怎样的文档

这不是零散教程的堆叠，而是一条**自底向上的知识阶梯**。目标读者是有计算机与数学的大学基础、但对"大模型 / Agent"没有系统认知的人。读者可以按序推进，也可以按需跳转。

整套文档有四个设计原则：

1. **从第一性原理出发**——每个概念先讲"它解决什么问题"，再讲"它怎么实现"。
2. **抽象分层，逐级收敛**——从数学 → 机器学习 → 深度学习 → NLP → 大模型 → Agent，每一层都是下一层的地基。
3. **一手源码实测**——本目录就坐在 `deepseek-harness` 源码仓库里，关键章节会直接锚定到 [packages](../packages) 与 [docs](../docs) 的真实实现。
4. **可验证、可动手**——每个主题都附思考题与参考答案；第 `01`~`03` 章和第 `10` 章还配有动手练习。

## 如何使用

- **顺序学习**：从 `01` 到 `11`，理解每层如何支撑上一层。
- **按需查阅**：遇到某个概念，用左侧搜索框直达，或查[术语表](reference/glossary.md)。
- **结合源码**：第 `08`~`10` 章的正文会直接引用 `deepseek-harness` 的真实文件与路径，边读边看真实现。
- **动手验证**：`10 实战 Lab` 里的练习需要本仓库已经 `pnpm install` 完成。

## 学习原则

- **地基优先**：跳层的代价是"看似懂了、一细问就塌"。`01`~`04` 是投资回报最高的部分。
- **做笔记**：每个主题的「思考题」是本页的核心，先自己写答案再看参考答案。
- **读一手材料**：tutorial 和博客帮助入门，但能读懂论文与源码才算真正掌握。
- **动手 > 观看**：Agent 的绝大部分知识只有在调试真实系统时才内化。
