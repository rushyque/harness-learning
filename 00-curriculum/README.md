# 学习路线

> 从"只有大学基础"到"能独立理解并改进一个真实 Agent 系统"，需要多长时间、读什么、怎么做。这一页是整套文档的导航图。

## 你在哪里

如果你是本文档的目标读者，大概率符合下面几条中的多数：

- 学过线性代数、概率论、微积分，但没怎么"用过"它们。
- 会写 Python（或能快速上手），处理过简单数据，但没做过机器学习项目。
- 用过 ChatGPT / DeepSeek 等对话产品，也看过一些 Agent 的宣传，但对内部机制是黑盒。
- 想成为这个领域的专家，而不只是会用工具。

这就够了。本文档假设你**不预先知道**什么是 Transformer、什么是 Reward Model、什么是工具调用——这些会从第一性原理一步步建立。

## 三条并行的学习轴

只读书会陷入"懂概念、不会用"。只写代码会陷入"会调库、不懂原理"。所以用三条轴并进：

1. **概念轴**（`01`~`07`）：建立从数学到 LLM 的系统理论。
2. **系统轴**（`08`~`09`）：理解 Agent 的组成与框架设计范式。
3. **动手轴**（`10`）：在 `deepseek-harness` 源码上读代码、改代码、跑通真实任务。

推荐的推进节奏是「一章概念 + 一个动手练习」，不要长期只看理论。

## 路线图与时间预期

> 下面按"每天投入 2 小时、每周 4~5 天"估算。快慢取决于你已有的基础，量级比精确天数更值得关注。

| 阶段 | 章节 | 目标 | 大致耗时 |
|---|---|---|---|
| 地基 | 01 数学、02 编程 | 能流畅做矩阵/概率运算，写干净的 Python | 4~6 周 |
| 方法 | 03 机器学习 | 建立"模型–损失–优化–评估"的心智模型 | 4~6 周 |
| 能力 | 04 深度学习 | 亲手训练一个神经网络，理解反向传播 | 4~6 周 |
| 语言 | 05 NLP 与 Transformer | 读得懂 Transformer 结构图与注意力公式 | 4~6 周 |
| 核心 | 06 LLM 原理、07 LLM 工程 | 理解预训练/对齐/推理/评估全链路 | 6~8 周 |
| 衔接 | 08 Agent 基础 | 知道 Agent 由哪些部件组成、怎么协作 | 3~4 周 |
| 精通 | 09 Agent 架构、10 实战 | 能读源码、改插件、设计自己的 agent | 6~8 周 |
| 纵深 | 11 安全治理 | 建立工程化与责任意识 | 持续 |

合计约 6~10 个月的持续投入，能达到"能读懂论文、能上手改真实 open-source agent 系统"的专家级起步。

## 每一页的结构

为了让学习可验证，本库每页尽量遵循统一结构：

1. **本节目标**——读完你应该能回答的问题。
2. **正文**——概念讲解，从"解决什么问题"开始。
3. **思考题与参考答案**——先自己作答，再对照想法。
4. **动手练习**——可以落在笔记本或源码里的练习。集中在第 `01`~`03` 章（打基础）与第 `10` 章（真实仓库），中间章节以思考题为主。
5. **源码锚点**——把概念锚定到 `deepseek-harness` 的真实实现。系统类章节 `08`~`10` 每页都有；数学与算法基础章 `01`~`07` 的对象是通用方法而非本仓库代码，故只在确有对应实现处给出锚点。

## 从零开始的建议顺序

**最简可行路径**（时间紧，只想快速到达 Agent）：

```text
00 学习路线
  → 01 数学（只读"最小子集"：向量/Jacobian、概率与熵、梯度）
  → 02 Python（NumPy 足够写练习即可）
  → 03 机器学习（重点：正则化与评估）
  → 04 深度学习（重点：反向传播、优化）
  → 05 Transformer（重点：Attention 公式、位置编码）
  → 06 LLM 原理 → 07 LLM 工程（对齐/推理）
  → 08 Agent 基础 → 09 Agent 架构
  → 10 实战 Lab（边学边写）
```

## 自我评估：你在第几层

在每个阶段开始前，用下面的清单自测，决定是否跳层：

- **可以跳过 01/02**：能解释矩阵乘法的意义、会手写小规模概率计算、能流畅写带类型和测试的 Python。
- **可以跳过 03**：能自己设计并调好一个带正则化的分类模型，并解释训练集/验证集/测试集为什么分开。
- **可以跳过 04**：能画出含两层卷积的网络结构并手推反向传播，理解 BatchNorm 为什么有用。
- **可以跳过 05**：能自己从零实现一个简化 Attention，并解释为什么需要位置编码。
- **可以跳过 06/07**：能解释训练三阶段、KV cache 的作用、RLHF 与 DPO 的差别。

如果某一项只能"大概知道"，就把那一章读透。
