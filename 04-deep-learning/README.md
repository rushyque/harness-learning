# 04 深度学习

> 目标：亲手搞懂神经网络——它是如何用"一层层的可微变换 + 反向传播"从数据里学出能力的。这是理解 LLM 与 Agent 推理的直接前置。

## 为什么这是关键一章

大语言模型本质上是"非常大、非常深的神经网络"。如果不理解反向传播、优化器和训练技巧，LLM 就永远是一个"玄学黑盒"。这一章把这些黑盒打开。
