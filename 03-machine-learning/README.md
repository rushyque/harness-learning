# 03 机器学习

> 目标：建立理解一切学习系统的核心心智模型：**模型 + 损失 + 优化 + 评估**。这一章是通往深度学习和 LLM 的方法论地基。

## 核心心智模型

几乎所有机器学习都能套进一个四件套：

```text
模型（怎么预测） + 损失（预测有多错） + 优化（怎么改进） + 评估（是否真的更好）
```

哪怕是大语言模型，也只是这个框架的极端放大版。先把这四个零件吃透。
