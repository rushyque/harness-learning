# 06 LLM 原理

> 目标：理解"大语言模型是什么、它内部怎么工作、为什么规模会带来能力"。从这里开始，我们进入 Agent 的真正大脑。

## 核心问题

你每天都在和它们对话，但它们的原理其实可以归结为几个可回答的问题：模型由什么组成？训练分哪几步？为什么参数越多越聪明（缩放定律）？上下文窗口到底是什么？
