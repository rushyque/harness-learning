# 01 数学基础

> 目标：把大学数学从"考试科目"变成"理解机器学习的直觉工具"。只学后续真正用得到的部分，不追求数学专业深度。

## 为什么先学数学

机器学习和大模型的绝大多数概念，本质上都是这里的三个工具的组合：**用向量和张量表示数据**、**用概率衡量不确定性**、**用求导和优化去学习参数**。数学不是"挡路的门槛"，而是让概念"不塌"的地基。
